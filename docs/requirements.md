# 要件定義書

## プロジェクト概要
- **プロジェクト名**: Desktop Mate Mac
- **目的**: macOS向けデスクトップマスコットアプリケーション（趣味プロジェクト）
- **ターゲット**: macOS 14.0以降
- **キャラクター**: 1種類（デフォルトキャラクター）

## 機能要件

### Phase 1: 基本表示と操作
- [ ] 透明背景のウィンドウ表示
  - タイトルバーなし
  - 常に最前面
  - クリックスルー（キャラクター以外）
- [ ] キャラクター画像の表示
  - PNG画像（512x512px）
  - 透過背景
- [ ] ドラッグで移動
  - キャラクターをドラッグして好きな位置に配置
- [ ] 待機アニメーション
  - 2-3枚の画像をループ再生
  - FPS: 2-3程度

### Phase 2: アニメーション拡張
- [ ] 歩行アニメーション
  - 左右の向き対応
  - 4-6枚のフレーム
  - FPS: 8-10程度
- [ ] ランダムに画面を歩き回る（半自動）
  - 待機状態が一定時間続いたらランダムに移動開始
  - 目的地に到達したら待機に戻る
  - 画面端の検出・処理

### Phase 3: インタラクション
- [ ] クリックで反応
  - キャラクターをクリックすると反応アニメーション再生
  - 1回再生後、元の状態に戻る

### Phase 4: 設定機能
- [ ] キャラクターのサイズ変更
  - スライダーで調整
  - 範囲: 100px 〜 300px
- [ ] ログイン時に自動起動
  - チェックボックスでON/OFF

## 非機能要件

### パフォーマンス
- CPU使用率: 常時5%以下
- メモリ使用量: 100MB以下
- バッテリー影響: 最小限
- アニメーションは滑らか（カクつかない）

### 使いやすさ
- 邪魔にならない
- 簡単に移動・サイズ変更できる
- 設定は最小限

## 技術制約
- macOS 14.0以降
- Swift + SwiftUI
- サードパーティライブラリは使わない
- 2Dイラストのみ

## 必要なアセット

### イラスト
1. 待機: 2-3枚（優先度: 高）
2. 歩行: 左3枚、右3枚（優先度: 中）
3. 反応: 2-3枚（優先度: 低）

### ファイル仕様
- 形式: PNG
- サイズ: 512x512px
- 背景: 透過
- 命名: `character_[animation]_[frame].png`

## 開発スケジュール（目安）

- Week 1-2: Phase 1（基本表示）
- Week 3-4: Phase 2（歩行・自動移動）
- Week 5-6: Phase 3（クリック反応）
- Week 7-8: Phase 4（設定画面）

## 成功基準
- ✓ 動作が軽快
- ✓ キャラクターが可愛く動く
- ✓ 作業の邪魔にならない
- ✓ 設定が簡単
